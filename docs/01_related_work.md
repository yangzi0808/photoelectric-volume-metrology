# 01 相近开源方案调研

检索日期：2026-11-10。

## 1. 先确认比赛真正优化的问题

赛题详细说明给了两个重要先验：

1. 三类目标形状已知；
2. 摆放姿态固定，缺口方向固定，圆柱轴线竖直，盲槽朝上。

同时，规则允许操作员预先选择形状模式，只要求尺寸在现场测得。因此本题不是
“任意物体通用三维扫描”，而是“已知几何模型、未知参数的非接触尺寸测量”。
这使参数化轮廓测量比完整稠密重建更有优势。

评分门槛也改变了技术优先级：

- 四种基础测量每次相对误差不超过 5% 即得该次满分；
- 同一目标两次一致性占 10 分；
- 四次基础测量必须快，盲槽是完成基础项后的附加题。

体积是尺寸的乘积，因此单个边长 1% 的误差通常会传播成 1% 至 3% 的体积误差。
主要矛盾是亚像素边缘、尺度标定和重复性，而不是点云的面片数量。

## 2. 源码案例分析

### 2.1 激光线转台扫描

[pablolird/laser-scanner-3d-reconstruction](https://github.com/pablolird/laser-scanner-3d-reconstruction)
使用固定相机、固定绿色线激光和 2° 步进转台，从单目照片做光线与激光平面求交，
不依赖现成三维重建库。项目采用 MIT License。

可借鉴部分：

- `solvePnP`/标定 → 像素反投影 → 射线与激光平面求交；
- 开/关激光差分可降低环境光影响；
- 逐行峰值与亚像素质心；
- 按转台角度把点云转回物体坐标；
- 物理边界裁剪可去除转台反射造成的离群点。

关键警示：该项目使用 6 个手工点标定，重投影误差约 9.8 px，最终中位几何误差
约 3.2 mm。作者自己判断主要误差来自相机位姿，而非激光提取。这说明本队必须用
棋盘格/ChArUco 多视图标定和亚像素角点，不能照搬手工选点。

[giulioz/laser-scanning](https://github.com/giulioz/laser-scanning)
也实现了相机内参、棋盘格参考面、HSV 激光提取、Open3D 点云输出；仓库主页没有
项目级许可证，因此只适合作为算法阅读材料，不应直接复制代码。

[qicecrem/TurntableLaser3DScanner](https://github.com/qicecrem/TurntableLaser3DScanner)
是较完整的 STM32 + Qt + OpenCV + Open3D 系统，包含相机内参、激光平面和转台轴
三步标定、串口 CRC 协议、激光开关状态机、逐行亚像素质心。其三层标定接口对本
项目很有参考价值；但仓库未发现覆盖整个项目的许可证，只能借鉴结构，不能复制实现。

结论：线激光是盲槽深度的高价值局部工具，但整机若只做线激光稠密扫描，会引入
标定、遮挡、反光、运动同步和体素封闭等额外误差，对 5% 目标并不经济。

### 2.2 格雷码/相移结构光

[pranavkantgaur/3dscan](https://github.com/pranavkantgaur/3dscan)
实现格雷码与相移结构光，项目为 MIT License，内含投影图案、相位展开、相机与
投影器标定、三角化、点云配准和论文。优点是稠密、坐标定义统一；代价是投影器
非线性、相位展开、标定流程、投影图案数量和代码工程化都较重。

[nikolaseu/neuvision](https://github.com/nikolaseu/neuvision)
是 GPL-3.0 的完整结构光扫描系统，采用 C++/Qt，工程成熟度高。它说明一个可现场
运行的结构光系统绝不只有“投几张条纹”代码，还包含相机驱动、投影、标定、点云
处理和 UI。GPL 许可证也会影响后续代码分发方式。

[feiran-l/Structured-light-stereo](https://github.com/feiran-l/Structured-light-stereo)
使用双目与结构光组合，思路是把投影纹理作为双目匹配特征。双目相机的左右目图像
在本赛题中允许采集，但深度算法必须由参赛队实现；没有纹理的 PLA 平面正是普通
双目匹配的难点，主动投影可解决这问题，但增加同步与标定复杂度。

结论：结构光适合通用曲面，但对本题已知平面组合形状属于“能力过剩”。可作为
课题后续方向，不建议作为第一版基础方案。

### 2.3 轮廓法/视觉外壳

[TendoPain18/DIY-3D-Scanner-Python](https://github.com/TendoPain18/DIY-3D-Scanner-Python)
给出树莓派、USB 相机、步进电机转台和 shape-from-silhouettes 的低成本硬件路线，
为 MIT License。其 README 当前仍处于分阶段搭建状态，配套软件尚未完整提交，不能
直接当作可运行成品。

轮廓法的优势是对材质颜色不敏感、硬件便宜、实时性好，尤其适合 L 形块、圆柱外圆
和高度。其理论缺点是只能恢复视觉外壳；凹槽、通孔内部以及盲槽深度不能单靠外部
轮廓确定。这与附加题正好互补：外轮廓用轮廓法，内部深度用局部激光。

### 2.4 平面尺寸测量与标定

[MaidulHasan/VisionMeasure](https://github.com/MaidulHasan/VisionMeasure)
用已知 A4 纸做尺度参考，通过轮廓和旋转矩形测量物体长宽，MIT License。它证明
固定工作距离下“参考标定 + 单目轮廓”成本低且实现快，但只给二维尺寸，且对光照和
背景敏感。

[OpenCV 相机标定教程](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)
和 [ChArUco 检测文档](https://docs.opencv.org/4.x/df/d4a/tutorial_charuco_detection.html)
给出了本项目应采用的参数标定基线。ChArUco 同时利用 ArUco 编码和棋盘格角点，
比手工点选更适合现场快速、可重复标定。

## 3. 方案横向比较

| 路线 | 基础精度潜力 | 凹槽/孔能力 | 硬件成本 | 开发风险 | 8 分钟适配 | 本题评价 |
|---|---:|---:|---:|---:|---:|---|
| 普通双目自实现深度 | 中 | 中 | 中 | 高 | 中 | 纹理弱、边缘处易失败 |
| 条纹/格雷码结构光 | 高 | 外表面较好，遮挡区弱 | 中高 | 高 | 中 | 能力过剩、调参成本高 |
| 线激光全周扫描 | 中高 | 可测盲槽局部深度 | 低中 | 中高 | 中 | 易受反光、运动同步和遮挡影响 |
| 纯轮廓/视觉外壳 | 外尺寸高 | 内部特征弱 | 低 | 低中 | 高 | 最适合基础目标外轮廓 |
| 已知形状参数化测量 | 高 | 基础形状高；盲槽缺深度 | 低 | 低 | 高 | 与本题规则高度匹配 |
| **轮廓 + 固定侧视 + 激光测深** | **高** | **基础高，盲槽可补深** | **低中** | **中** | **高** | **推荐主方案** |

## 4. 选型结论

主方案采用混合测量：

1. 顶部背光轮廓测量 `a、b、u、v、D、d`；
2. 固定侧面轮廓测量 `h` 或 `H`；
3. 对盲槽使用自建线激光三角测量只恢复槽深 `t`；
4. 根据已知形状公式计算实体体积，而非对带孔点云直接做凸包或体素封闭；
5. 自动判型只做辅助，正式比赛优先使用规则允许的显式形状模式，降低误判风险。

该路线不依赖厂商深度图、点云、三维模型、SDK 尺寸或体积结果，符合详细规则中
“参赛队自行完成图像处理、深度解算、三维重建及体积计算”的要求。

## 5. 检索方法与可复现关键词

使用 GitHub 仓库搜索和项目源码阅读，主要关键词：

```text
laser line scanner python opencv
structured light 3d scanner
visual hull reconstruction silhouette
object dimension measurement opencv
charuco camera calibration
stereo vision object measurement opencv
turntable laser scanner
silhouette based 3d reconstruction
```

筛选标准：

- 是否包含从图像到几何量的完整链路；
- 是否明确说明标定和误差；
- 是否有许可证；
- 是否能在普通相机、低功率激光和普通计算硬件上复现；
- 是否能针对本题的 L 块、通孔圆柱和盲槽实际提高得分。

## 6. 不直接采用的开源代码

- 无许可证仓库只做阅读参考，不复制实现；
- GPL 仓库若直接并入，需要接受相应分发义务，比赛代码可参考架构但应独立实现；
- 依赖 RealSense/ToF/厂商 SDK 的直接深度输出不作为测量源；
- 依赖大型学习模型但缺少本赛题训练/验证数据的项目不进入主路径。
