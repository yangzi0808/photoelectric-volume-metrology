# 02 初步解题思路与执行计划

## 1. 推荐方案

### 名称

**Known-Shape Metrology：背光轮廓 + 固定侧视 + 局部激光测深**

### 核心思想

把四个目标参数测准，再代入官方体积公式。目标不是恢复十万个点，而是用最少的
高精度观测量得到尺度、轮廓和槽深。

```text
顶部背光图像  -> 外轮廓 / 缺口 / 内孔 -> a, b, u, v 或 D, d
固定侧视图像  -> 顶边与基准底边       -> h 或 H
线激光剖面    -> 顶面与槽底两级高度   -> t
标定参数      -> 像素/毫米、相机内参、激光平面、基准面
                         |
                         v
        已知形状实体体积 + 不确定度 + 质量门限
```

## 2. 三种目标的具体模型

### L 形块

```text
V1 = (a*b - u*v) * h
```

顶部紧包围盒给出外长 `a`、外宽 `b`。缺口是紧包围盒中与一个角相邻的开口区域，
其两个方向跨度给出 `u、v`。固定侧视给出等高的 `h`。

工程增强：

- 四条外边分别做直线拟合，取平行线距离而非单个包围盒像素；
- 缺口的两个边界先做直线拟合，再投影到标定平面；
- 通过对置边线求交恢复四个外角，减小旋转与透视残差。

### 带通孔圆柱

```text
V2 = pi/4 * (D^2 - d^2) * H
```

顶部背光时，实体环为暗、通孔为亮。外边界做 RANSAC 圆拟合得到 `D`，内边界做
圆拟合得到 `d`；侧视轮廓给出 `H`。圆心仅用于质量检查，不把孔中心位置输入体积。

工程增强：

- 用圆拟合而不是横纵包围盒均值；
- 外圆和内圆同心度作为失效门限；
- 端面倾角只做质量告警，不擅自修正高度公式。

### 矩形盲槽块

```text
V3 = a*b*h - u*v*t
```

顶部轮廓给出 `a、b、u、v`，侧视给出 `h`。线激光扫过槽口，自建激光平面求得
顶面与槽底的三维点；使用两级深度稳健估计得到 `t`。

工程增强：

- 槽底点必须与槽口 ROI 相交，不能接受任意低层点；
- 至少两条方向不同的激光剖面或转台多角度采样；
- 槽底与顶面各要求最小点数，否则不锁定结果；
- 两级中心差、残差、内侧点比例共同形成质量分。

## 3. 光学与机械布置

### 基础版（L 块和通孔圆柱）

- 顶部单色相机，垂直向下；
- 半透明/磨砂测量台下方均匀背光；
- 固定侧面相机观察高度，背景与物体形成明显对比；
- 所有相机和测量台固定在同一刚性框架；
- 计算机、显示器、通用电源不计入规则尺寸，计算主机可外置。

### 盲槽增强

- 低功率线激光器固定在测量台侧上方；
- 激光平面与相机夹角建议 25° 至 45°，兼顾深度灵敏度和遮挡；
- 可选低速转台，仅在盲槽测量时转动 8 至 12 个角度；
- 激光开关、相机曝光和转台位置由程序同步，不让操作员手工移动目标。

### 安全

- 使用 1 类或明确标称的低功率线激光；
- 激光只在局部扫描时开启；
- 对开放光路加挡板/遮光罩，避免扫到人眼；
- 不使用大功率、无标识或需要开放光路观察的激光器。

## 4. 现场测量流程

1. 准备阶段固定相机、背景、背光和激光，加载预存标定参数；
2. 放入独立标定块，检查尺度与高度基准，不接触目标；
3. 选择 `L_BLOCK` 或 `CYLINDER` 模式；
4. 程序锁定曝光和白平衡，清除本次缓存；
5. 采集顶部背光图、侧面图和参考背景；
6. 提取外边界、缺口/内孔和侧面高度；
7. 做范围、单调性和不确定度门限检查；
8. 首次有效结果自动锁定并记录图像哈希、参数、尺寸、体积、用时；
9. 完成四次基础测量后，若剩余时间充足，再进行盲槽两次测量。

## 5. 评分导向策略

### 准确度 40 分

- 优先保证两种基础目标，不在基础项未完成时调试附加题；
- 显式选择形状模式，自动判型只做二次校验；
- 以亚像素拟合和标定误差预算为主，不追求密集点云；
- 每件结果保留原图、标定版本、中间尺寸和软件版本。

### 一致性 10 分

- 相机、灯具、台面固定；
- 曝光、增益、白平衡和背景图使用同一配置；
- 每次重新检测完整轮廓，不复用上一件目标的局部尺寸；
- 同一目标两次测量记录原始特征和最终结果。

### 效率 10 分

- 基础目标目标用时：每件不超过 10 至 15 s，两次总用时不超过 60 s；
- 不做全周 180° 点云扫描，除非质量门限失败；
- L 块和圆柱只需顶部、侧面各一帧；
- 结果锁定后立即进入下一件，避免反复计算。

### 附加题 20 分

- 基础四项全部提交后开始；
- 两次盲槽共用一套已标定参数；
- 若激光两级分离度或槽底点数不足，应快速重扫指定角度，不做无界等待。

## 8. 风险与应对

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 上游规则变成随机未知三类形状 | 官方后续细则改变 | 保持显式模式主路径；副路径增加多视角视觉外壳和点云参数拟合，不依赖深度相机 |
| PLA 黑色/高反光导致边缘失败 | 轮廓断边、亮度饱和 | 背光轮廓为主；曝光锁定 + HDR；偏振片仅作辅助 |
| 圆柱顶部轮廓椭圆化 | 外圆横纵直径差大 | 相机垂直装调、平面单应校正、倾角告警 |
| 激光斑点/反光 | 两级聚类不收敛 | 多帧平均、双侧或两方向剖面、限制 ROI |
| 目标位置偏移出 ROI | 缺边或越界 | 大视场预检 + 软件自动 ROI，不人工拖动目标 |
| 高度基准受台面反光干扰 | 底边抖动 | 背光/哑光基准条，固定基准面和标定块 |
| 8 分钟内附加题拖累基础项 | 基础项耗时超限 | 基础项完成即锁定成绩，附加题设硬超时 |

## 9. 决策门

在投入全部硬件前设置三个闸门：

1. **标定门**：已知长度重复测量误差不超过 0.2%；
2. **基础形状门**：L 块和圆柱各至少 20 次，p95 体积误差不超过 2%；
3. **盲槽门**：槽深误差不超过 0.5 mm，否则只能把附加题作为非主路径。

若第 1 或第 2 门失败，先修正相机装调、尺度标定和边缘提取，不进入盲槽扩展。
