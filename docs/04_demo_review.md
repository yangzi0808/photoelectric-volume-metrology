# 04 Demo 自测、不足与修改方案

> 本文记录第一版二值 mask MVP 的复盘。其整数边缘、台面视差和自动判型问题已在
> 第二轮修复，新的原图压测结果和代码审计见
> [05_competitive_upgrade_and_validation.md](05_competitive_upgrade_and_validation.md)。

## 1. 当前 Demo 证明了什么

可执行命令：

```powershell
python -m volumecv demo --out output\demo
python -m unittest discover -s tests -v
```

Dashboard 中的三个目标覆盖：

- L 形块的紧包围盒与角缺口；
- 通孔圆柱的封闭内孔和自动判型；
- 盲槽块的封闭槽口与两级激光深度。

代码完成了从轮廓/深度输入到体积、风险提示和可追溯 JSON 的闭环。默认演示还
执行随机尺寸合成基准，包括：

- 外形尺寸随机；
- 顶部和侧面像素尺度随机；
- 1 像素膨胀/腐蚀；
- 千分级标定偏差；
- 激光噪声和离群点；
- 每件两次独立测量。

本次固定随机种子的基线结果：

| 目标 | 真值/cm³ | 首次测量/cm³ | 相对误差 | 两次差异 |
|---|---:|---:|---:|---:|
| L 形块 | 290.928 | 290.815 | 0.039% | 0.17% |
| 通孔圆柱 | 354.673 | 354.793 | 0.034% | 0.09% |
| 盲槽块 | 374.756 | 375.030 | 0.073% | 0.07% |

210 次随机重复测量的平均绝对误差为 0.515%，p95 为 1.266%，5% 门槛通过率
100%，无判型或几何提取失败。这个结果说明参数模型和接口值得继续做硬件验证。

扩大到 1,200 次后，平均绝对误差为 0.529%，p95 为 1.282%，最大为 2.070%，
仍为 100% 通过 5% 门槛且无提取失败。重复差异均值为 0.779%，p95 为 1.902%。
这说明当前整数像素压力测试的主要短板是重复一致性，而不是完全失效。

## 2. 应如何解释结果

合成测试的低误差只能说明：

1. 几何参数提取逻辑正确；
2. 公式和单位换算正确；
3. 对模拟的边缘量化和标定偏差具有一定鲁棒性；
4. 自动判型在三类理想轮廓上工作。

它不能说明：

- 真实相机的动态范围和噪声；
- 背光边缘能否稳定到亚像素；
- 激光在 PLA 上是否形成可分离的两级点；
- 夹具刚度、热漂移和现场光照影响；
- 5% 实测误差已经达到。

答辩时必须明确“当前为合成算法验证”，否则现场实物数据会与材料不符。

## 3. 当前主要不足

### P0：缺少真实采集链路

程序接收二值 mask，而不是相机原图。真实系统还缺：

- 相机同步和曝光锁定；
- 背光/激光 GPIO 或串口控制；
- 空背景图像；
- 可复现触发和帧丢包检查。

修改方案：

- 使用工业 USB 相机或可手动锁曝光的 UVC 相机；
- 优先用黑白全局快门；
- Python/OpenCV 采集，配置保存在 YAML/JSON；
- 采集器返回 `CaptureBundle`，测量核心不直接依赖设备；
- 为每帧记录序号、时间戳、曝光和触发状态。

### P0：轮廓仍假设固定方向和整数像素

当前 L 块缺口依赖轴对齐轮廓，圆柱尺寸依赖包围盒。现场相机会有轻微旋转、
透视、模糊和边缘偏置。

修改方案：

- 在毫米坐标下做直线/圆拟合；
- 对缺口方向先自动识别，再按固定模式校验；
- 对圆柱使用外/内圆 RANSAC，检查圆度、同心和残差；
- 用正反阈值扫描估计边缘偏置，降低背景明暗造成的系统性缩放。

### P0：盲槽深度数据仍是模拟数组

当前激光模块验证了“有两级高度时如何稳健求深”，尚未验证激光成像和三角化。

修改方案：

- 增加激光平面标定；
- 从原图提取激光中心线；
- 做光线-平面求交；
- 槽口 ROI 内分离顶面和槽底；
- 至少两个方向/角度剖面；
- 记录两级中心差和槽底点比例。

### P1：没有台面基准和倾斜检查

物体未完全放平、台面有灰尘或相机轻微移动会造成高度和尺度偏差。

修改方案：

- 固定基准条/基准角；
- 每次测量先检测基准；
- 侧面底边和顶边分别拟合，倾斜超过门限直接提示；
- 记录目标相对测量台坐标系的位置。

### P1：不确定度过于乐观

当前模型只包含边缘、尺度和激光采样。真实系统误差往往相关，例如同一尺度误差
会同时影响 `a、b、u、v`，不是独立误差。

现有压力测试也暴露了这个问题：虽然体积误差都低于 5%，但预测的两倍标准差区间
只覆盖了 66.17% 的合成样本，而不是接近 95%。因此当前“预测不确定度”只能用于
排序风险，不能直接作为答辩中的完整误差界。

修改方案：

- 从 20 至 30 个标准块测量拟合经验误差模型；
- 加入共模尺度项和夹具温漂项；
- 用留出集校准预测误差，而不是用训练集；
- 把预测区间覆盖率作为标定指标。

### P1：自动判型不够强

当前分类规则对合成形状清晰。真实背光轮廓可能在圆柱外缘、槽角和反光处断开。

修改方案：

- 正式比赛使用显式形状模式；
- 自动判型只提供“一致/异常”校验；
- 若候选置信度低，不擅自切换公式；
- 在准备阶段用形状选择按钮或键盘快捷键。

### P2：没有时间和资源预算控制器

程序能计算单次测量，但没有针对 8 分钟总时间的调度。

修改方案：

- 主状态机记录基础项完成数和总用时；
- 基础项结束前禁止进入附加题；
- 附加题设置硬超时；
- 重扫只在质量门限失败时触发；
- 结果提交后不可修改。

### P2：没有现场故障恢复 UI

规则允许异常人工重启一次且计时继续。当前没有恢复流程。

修改方案：

- 自动保存每帧和状态；
- 启动时检测未完成测量；
- 只从安全检查点恢复，保持程序和参数不变；
- 重启后要求操作员确认，不自动改写已锁定结果。

## 4. 下一版实现顺序

1. 购买/借入相机、背光源和低功率线激光，搭建固定框架；
2. 完成 ChArUco 内参与顶部毫米平面标定；
3. 用真实背光图像替换 mask 输入；
4. 实现亚像素直线和圆拟合；
5. 用已知尺寸标准块闭环测量；
6. 接入激光平面和盲槽剖面；
7. 加状态机、结果锁定和日志；
8. 做现场条件压力测试。

在第 5 步以前，不建议把资源转到 GUI、点云美化和海报排版。

## 5. 后续方向

### 主线方向

- 单目顶部计量 + 侧面计量 + 激光局部深度；
- 结构化误差预算与自动质量门限；
- 低热漂移框架和快速日检；
- 结果可追溯与一键复现。

### 可选研究方向

- 结构光提高通用曲面能力；
- 双目自实现与主动投影融合；
- 多视角视觉外壳作为自动化兜底；
- 学习型轮廓分割仅作辅助，不作为核心尺度来源；
- 若官方允许商用双目相机，也仍需自建匹配、三角化、重建和体积算法。

## 6. 最终验收建议

比赛前至少完成以下组合：

```text
基础形状：每类 30 次
位置扰动：中心 ±20 mm
光照变化：3 种
连续运行：30 min
冷启动：5 次
盲槽：每深度 20 次
故障注入：相机掉线、串口超时、单帧遮挡
```

通过标准：

- 基础目标无人工描边/读尺寸/改结果；
- 4 次基础测量用时 <2 min；
- 5% 误差通过率 >98%；
- 同目标两次相对差 p95 <1%；
- 所有失败均能给出明确质量原因；
- 原始图像、标定版本、尺寸和结果可一一对应。
